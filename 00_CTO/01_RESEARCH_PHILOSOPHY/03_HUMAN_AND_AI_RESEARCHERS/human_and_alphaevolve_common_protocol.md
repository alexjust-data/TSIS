# Human And AlphaEvolve Common Protocol

Fecha: 2026-07-05
Estado: protocol_principle_initial

## Tesis

Un humano y AlphaEvolve deben poder trabajar con la misma estructura de experimento.

La diferencia no debe estar en el contrato.

La diferencia esta en quien propone variantes.

```text
human_researcher -> candidate experiment
alphaevolve -> candidate experiment
```

Ambos pasan por:

```text
Scientific Validation Pipeline
```

## AlphaEvolve No Decide

AlphaEvolve puede proponer:

```text
sampling probes
parameter grids
reference functions
representation builders
event detectors
transition candidates
policy candidates
```

Pero no puede decidir:

```text
validated knowledge
production readiness
truth of state
truth of outcome
lineage rewrites
leakage gate disabling
```

## Humano No Decide Por Autoridad

La intuicion discrecional humana puede crear seeds:

```text
+50% move
pre_event_30m
post_event_30m
DAS scanner ideas
visual case studies
```

Pero esos seeds son instrumentos de investigacion, no verdades finales.

## Regla

```text
same experiment object
same execution protocol
same validation pipeline
```
