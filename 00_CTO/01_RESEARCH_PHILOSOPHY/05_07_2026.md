`C:/TSIS_Data/03_TSIS_Lab` es mejor sitio para la operativa central de experimentos que `01_TSIS_DATA_FOUNDATION/01_research`.

La separacion correcta seria:

```text
C:/TSIS_Data/00_CTO

```

El corazon de TSIS no debe ser AlphaEvolve. Tampoco debe ser el backtest. Tampoco las tablas de estado.

El corazon debe ser:

```text
Scientific Validation Pipeline
```

Y la unidad minima ya no deberia ser:

```text

sampling probe
strategy
```

sino:

```text
research_experiment
```

```text
Research Experiment
```

Luego ambos pasan por la misma tuberia:

```text
Candidate Experiment
-> Execution
-> Evidence
-> Validation
-> Knowledge Object
-> Validated Knowledge
-> Operational Component
```
