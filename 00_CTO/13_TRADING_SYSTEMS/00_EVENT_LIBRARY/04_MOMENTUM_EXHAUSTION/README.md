# 04_MOMENTUM_EXHAUSTION

## Purpose

Capture events where a prior expansion starts to fail or lose force.

## Candidate Events

- `Bull_Trap_Event`
- `Failed_Breakout_Event`
- `Late_Day_Fade_Event`
- `Parabolic_Top_Event`

## Inputs

- intraday bars;
- prior momentum context;
- volume decay or liquidity deterioration signals;
- resistance and breakout context.

## Outputs

- exhaustion event definitions;
- detector requirements;
- outcome questions about fade, continuation and volatility.

## No-goals

This folder does not define short entries or covering logic.
