# 06_RESISTANCE_AND_BREAKOUTS

## Purpose

Capture events around relevant price levels.

## Candidate Events

- `Previous_Day_High_Breakout_Event`
- `PMH_Breakout_Event`
- `Resistance_Test_Event`
- `Daily_Level_Breakout_Event`

## Inputs

- daily levels;
- premarket levels;
- intraday bars;
- volume and liquidity context.

## Outputs

- level-interaction event definitions;
- detector requirements;
- outcome questions about breakout, rejection and trap behavior.

## No-goals

This folder does not define breakout entry timing.
