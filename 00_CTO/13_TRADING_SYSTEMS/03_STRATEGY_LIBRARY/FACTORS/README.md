# FACTORS

Estado: TSIS strategy factor workspace.

Esta carpeta queda reservada para factores propios de TSIS, consolidados o en
investigacion, que puedan condicionar multiples estrategias.

No debe contener subcarpetas por trader.

Los factores derivados de enseñanzas de un trader viven en la carpeta del
trader correspondiente.

Ejemplo:

```text
03_STRATEGY_LIBRARY/01_Steven_Dux/FACTORS/
```

Regla:

```text
factor fuente de trader -> carpeta del trader
factor TSIS propio -> FACTORS/
```

Un factor TSIS puede nacer inspirado por un trader, pero solo debe moverse aqui
cuando TSIS lo trate como factor propio, mantenible y aplicable fuera de esa
fuente.
