# 04_STRATEGY_RESEARCH

Estado: design surface.

## Purpose

Define how strategy candidates are evaluated after events and outcomes exist.

## Inputs

- `event_table`
- `outcome_table`
- Strategy Library;
- Execution Models;
- cost, slippage and risk assumptions.

## Outputs

- strategy result specifications;
- walk-forward requirements;
- robustness checks;
- failure mode evidence;
- promotion or rejection notes.

## No-goals

This folder does not hold raw backtest output or replace module-level run
manifests.
