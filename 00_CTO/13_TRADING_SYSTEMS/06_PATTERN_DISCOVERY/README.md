# 06_PATTERN_DISCOVERY

Estado: design surface.

## Purpose

Capture patterns discovered from data rather than assumed by humans.

## Inputs

- event tables;
- outcome tables;
- audited market data;
- feature candidates;
- pattern mining outputs when governed.

## Outputs

- candidate patterns;
- support and stability notes;
- links to event families;
- promotion candidates for Event Library or Edge Hypotheses.

## No-goals

Do not treat an observed pattern as a strategy or institutional edge without
validation.
