# 07_CLUSTER_RESEARCH

Estado: design surface.

## Purpose

Group market behaviors into families of states, trajectories or outcomes.

## Inputs

- events;
- outcomes;
- state representations;
- features;
- Pattern Discovery candidates.

## Outputs

- cluster definitions;
- cluster profiles;
- behavior families;
- links to Event Library and Decision Models.

## No-goals

This folder does not group tickers by company identity as its primary purpose.
