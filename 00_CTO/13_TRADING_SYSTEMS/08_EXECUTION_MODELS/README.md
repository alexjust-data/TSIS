# 08_EXECUTION_MODELS

Estado: design surface.

## Purpose

Define realistic execution assumptions and constraints.

## Inputs

- strategy candidates;
- liquidity data;
- spread data;
- halts and calendar;
- broker/exchange constraints when available.

## Outputs

- execution model specifications;
- slippage assumptions;
- partial fill assumptions;
- latency and halt handling;
- realism constraints for strategy evaluation.

## No-goals

Execution Models must not redefine events, outcomes or strategy thesis.
