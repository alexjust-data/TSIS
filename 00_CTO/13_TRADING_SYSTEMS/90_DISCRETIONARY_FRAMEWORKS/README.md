# 90_DISCRETIONARY_FRAMEWORKS

Estado: contained source material.

## Purpose

Contain discretionary frameworks, trader mental models and qualitative
observations that are useful but not yet mechanized.

## Inputs

- human trading experience;
- Sersan material after source separation;
- chart/tape observations;
- notes that are not yet formal events or strategies.

## Outputs

- explicit assumptions;
- candidate rules for distillation;
- questions for Event Library, Execution Models or Decision Models.

## No-goals

Discretionary knowledge does not govern detectors or evaluators until distilled
and promoted.
