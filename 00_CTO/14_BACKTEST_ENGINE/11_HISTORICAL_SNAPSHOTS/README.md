# Historical snapshots

Status: `NON_AUTHORITATIVE_EVIDENCE`

This directory preserves the files that existed before the governance baseline.
They are retained for provenance and audit reconstruction.

Rules:

- They do not define current state.
- Their old next-step pointers are superseded.
- Their singular `AGENT.md` naming is historical.
- Current authority lives in the root `README.md`, `AGENTS.md`,
  `LOCAL_RULES.md`, registers and gate records.
- No agent may resume work from a historical snapshot.
