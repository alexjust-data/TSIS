## Rol En TSIS

No define arquitectura tecnica, pero ayuda a fijar disciplina de ejecucion, pruebas y responsabilidad profesional.

**Utilidad principal:** normas operativas para trabajo largo con agentes, compromisos, tests y calidad de TSIS.

## Como Deben Usarlo Los Agentes

- Un agente no debe declarar una pieza completa si no ha verificado los criterios de aceptacion.
- Los compromisos deben ser concretos: artefacto, prueba, evidencia y estado.
- La presion por avanzar no justifica saltarse tests, manifests ni trazabilidad.
- Para TSIS conviene definir Definition of Done por modulo.
