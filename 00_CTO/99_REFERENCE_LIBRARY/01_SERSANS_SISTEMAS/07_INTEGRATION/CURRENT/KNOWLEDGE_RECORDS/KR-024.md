# KR-024 — Bollinger antitendencial: diario e intradía

## Alcance

Bollinger se estudia como sistema mean reverting cuya conducta cambia radicalmente con timeframe, horario, filtros y salidas. La práctica descubre además un error dimensional del stop ATR y deja abierta, no resuelta, la variante intradía.
