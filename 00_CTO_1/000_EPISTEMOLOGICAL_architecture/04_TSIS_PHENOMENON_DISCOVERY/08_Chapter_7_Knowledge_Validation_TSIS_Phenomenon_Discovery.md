# 7. Knowledge Validation

## 7.1 Purpose

Knowledge becomes scientifically useful only after rigorous validation.

The purpose of this chapter is to define how TSIS validates whether a
proposed knowledge object is sufficiently supported to become part of
the institutional research base.

Validation evaluates evidence, not profitability.

------------------------------------------------------------------------

## 7.2 Fundamental Principle

No knowledge object becomes canonical because it produced good
historical returns.

Knowledge becomes canonical only after surviving reproducible scientific
validation.

``` text
Hypothesis
    ↓
Evidence
    ↓
Phenomenon
    ↓
Knowledge
    ↓
Validation
```

------------------------------------------------------------------------

## 7.3 Validation dimensions

Every knowledge object shall be evaluated across multiple dimensions:

-   empirical support,
-   reproducibility,
-   temporal robustness,
-   population robustness,
-   regime robustness,
-   explanatory consistency,
-   falsifiability.

Failure in one dimension limits the scope of the knowledge claim.

------------------------------------------------------------------------

## 7.4 Reproducibility

Independent reconstruction using:

-   identical populations,
-   identical state versions,
-   identical feature registry,
-   identical protocols,

shall produce materially equivalent conclusions.

------------------------------------------------------------------------

## 7.5 Population robustness

Knowledge validated on one population shall not automatically
generalize.

Independent validation is required for:

``` text
Different liquidity
Different capitalization
Different regimes
Different exchanges
Different eras
```

------------------------------------------------------------------------

## 7.6 Regime robustness

Every knowledge object should explicitly state whether it is:

``` text
Regime-specific

Regime-dependent

Regime-invariant
```

The applicable scope becomes part of the knowledge itself.

------------------------------------------------------------------------

## 7.7 Contradictory evidence

Contradictory evidence shall never be discarded.

Instead it must be classified as:

-   limitation,
-   boundary condition,
-   competing explanation,
-   falsification.

Negative evidence improves scientific understanding.

------------------------------------------------------------------------

## 7.8 Confidence levels

Suggested confidence levels:

``` text
Exploratory
Supported
Replicated
Robust
Canonical
```

Confidence reflects evidence quality rather than prediction accuracy.

------------------------------------------------------------------------

## 7.9 Validation metadata

Every validated knowledge object shall record:

``` text
knowledge_id
validation_protocol
validation_population
control_population
state_version
feature_registry_version
confidence_level
known_limitations
last_validation_date
```

------------------------------------------------------------------------

## 7.10 Continuous validation

Validation is continuous.

New evidence may:

-   strengthen,
-   refine,
-   restrict,
-   or invalidate

existing knowledge.

Canonical status is therefore always conditional on the currently
available evidence.

------------------------------------------------------------------------

## 7.11 Constitutional rule

Scientific knowledge inside TSIS remains permanently open to revision.

No knowledge object is immune from re-evaluation.

Empirical evidence always has authority over prior conclusions.
