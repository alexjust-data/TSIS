# 13. Research Memory

## 13.1 Purpose

Scientific progress depends on cumulative memory.

The purpose of the Research Memory layer is to preserve every meaningful
research artifact generated during the lifecycle of TSIS so that future
investigations build upon previous evidence instead of repeatedly
rediscovering the same results.

Research memory is institutional memory.

It is not conversational memory.

------------------------------------------------------------------------

## 13.2 Fundamental Principle

Every experiment changes the knowledge state of TSIS.

Even when a hypothesis is rejected, the research produces information.

Therefore:

``` text
No governed experiment is ever lost.
```

Negative evidence is part of institutional knowledge.

------------------------------------------------------------------------

## 13.3 Research Memory hierarchy

``` text
Research Question
        ↓
Protocol
        ↓
Hypotheses
        ↓
Evidence
        ↓
Validation
        ↓
Knowledge
        ↓
Research Memory
```

Research Memory accumulates the complete history of discovery.

------------------------------------------------------------------------

## 13.4 Objects preserved

The Research Memory stores:

``` text
Research Questions

Protocols

Hypotheses

Evidence Sets

Validation Reports

Knowledge Objects

Rejected Hypotheses

Negative Results

Replication Studies

Revision History
```

It intentionally preserves failures.

------------------------------------------------------------------------

## 13.5 Why failures matter

Rejected hypotheses reduce future search space.

Examples:

``` text
Feature family rejected

Population mismatch

Insufficient evidence

Contradictory evidence

Regime dependency discovered
```

These results prevent duplicated effort.

------------------------------------------------------------------------

## 13.6 Memory versus Knowledge

Knowledge represents current validated scientific understanding.

Research Memory represents the entire scientific history.

Knowledge is therefore a curated subset of Research Memory.

------------------------------------------------------------------------

## 13.7 Traceability

Every memory object shall preserve lineage back to:

``` text
Research Question

Protocol

State Version

Representation Version

Feature Registry Version

Evidence Version
```

Nothing enters memory without provenance.

------------------------------------------------------------------------

## 13.8 Memory evolution

Research Memory is append-only.

Existing historical artefacts are never overwritten.

Corrections generate:

``` text
new versions

new reviews

new validation records
```

Historical context remains reconstructible.

------------------------------------------------------------------------

## 13.9 Retrieval

Every memory object should be retrievable by:

``` text
Research Question

Population

Phenomenon

Knowledge Object

Feature

Representation

Market Regime

Time Horizon
```

The objective is scientific reuse rather than document storage.

------------------------------------------------------------------------

## 13.10 Constitutional rule

Research Memory is the institutional scientific memory of TSIS.

Every governed investigation contributes permanently to that memory,
regardless of whether its conclusions are ultimately validated or
rejected.

Scientific progress is cumulative.
