Valores permitidos para `state_role`:

```text

at_event
post_event_review
research_replay
```

Solo `pre_event` y `at_event` con `consumption_legality = decision_safe` pueden llegar a ser ML feature candidates. `post_event_review` es contexto forense/research u outcome-adjacent, no input predictivo pre-evento ni at-event.


Clasificacion independiente de consumo:

```text
consumption_legality
```

Valores permitidos:

```text
decision_safe
research_only
outcome_adjacent
prohibited_as_input
```

Regla:

```text
state_role describe la relacion temporal con el evento.
consumption_legality decide si la fila puede usarse como input.
```

`post_event_review` puede ser valido para investigacion, pero debe ser `research_only` u `outcome_adjacent`; no puede ser `decision_safe` para prediccion en el timestamp del evento.
