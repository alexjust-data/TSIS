# 08_RUNTIME_CAPABILITIES

Status: `market_state_bounded_on_demand_reuse_eligibility_transition_review_closed_v0_1`
Date: `2026-07-25`

This folder records the runtime capability layer that sits after governed
representation architecture and before any repeatable on-demand generation. It now also records the first Market State on-demand capability design, the canonical Market State request contract, the Market State execution plan contract, the Market State profile resolver design, the Market State universe resolver design, the Market State source resolver design, the Market State partition/coverage resolver design, the Market State materializer design, the Market State validator design, the Market State candidate dataset registry design, the Market State run lifecycle/manifest design, the Market State on-demand execution-chain joint review, the first bounded on-demand execution authorization, the first bounded Market State on-demand execution run, its candidate dataset review, its deterministic rerun authorization, its deterministic rerun execution, its determinism validation review, its idempotency/reuse test authorization, the bounded idempotency/reuse test execution and the bounded exact-match reuse eligibility transition review.

It is not a Market State folder and not an Event State folder. It defines how
TSIS should turn a governed request into resolved profiles, sources, execution
plans, materialization, validation, registry entries and reproducible outputs
when later gates authorize those actions.
