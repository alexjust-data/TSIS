# Quotes Raw File Path References

Este manifiesto repara las referencias `file:` heredadas de los casepacks de `quotes`.

El dossier original apuntaba a un root historico de raw quotes diario que no esta disponible en esta maquina. Para no dejar paths rotos dentro de los casos, cada caso enlaza a esta pagina y conserva aqui su `relpath` historico.

La ruta disponible indicada abajo es el manifiesto local actual. Las particiones mensuales originales se conservan como relpath historico porque ya no existen como files fisicos en esta maquina.

Fuente local disponible: `E:\TSIS\data\data_foundation_outputs\ohlcv_1m_quote_guarded`

Manifiesto local disponible: `E:\TSIS\data\data_foundation_outputs\ohlcv_1m_quote_guarded\repair_manifest_lt1b_v0_1_sample.csv`
